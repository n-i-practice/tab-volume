# tab-volume Privacy Policy / プライバシーポリシー

## English

**Tab audio.** When you adjust or mute a tab, tab-volume processes its audio in memory on your device for playback. The extension discards the audio when the capture ends. It does not record or send tab audio to the developer or third parties.

**Web addresses and settings.** The extension reads the active tab's web address when you invoke it so it can match saved rules. When you choose to save a rule, the extension stores the volume and the selected URL components (hostname, path and selected query parameter names and values, depending on the rule). Display preferences are stored in the same browser profile using Chrome extension local storage. The extension does not send saved rules, addresses, or preferences off the device, and it runs without a developer account login or developer-side analytics.

**Retention and removal.** Rules and preferences stay in Chrome until you delete them or remove the extension. To delete a rule, use the trash icon in the popup or open **Saved settings** from the gear menu and delete it there. Removing the extension clears its local storage.

**Optional support link.** Selecting the Ko-fi button opens Ko-fi in a new tab. Any data you enter or payment you make there is handled under [Ko-fi's privacy policy](https://more.ko-fi.com/privacy).

tab-volume's use of information received from Google APIs adheres to the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#limited_use), including its Limited Use requirements. For questions, use the Support section of the tab-volume listing in the Chrome Web Store.

## 日本語

**タブ音声。** タブの音量変更やミュートを操作すると、tab-volume は再生のために端末のメモリー上で音声を処理し、キャプチャ終了時に破棄します。音声の録音や、開発者・第三者への送信は行いません。

**URL と設定。** 拡張を開いたタブの URL を読み取り、保存済みの条件との照合に使います。設定の保存を選んだ場合は、音量と、条件に含めた URL の部分（ホスト名、パス、選択したクエリパラメータの名前と値）を保存します。表示設定も含め、Chrome が管理するそのプロファイル内の保存領域に保持します。設定や URL の外部送信、開発者側での利用状況の計測、アカウント登録はありません。

**保持と削除。** 設定は、削除するか拡張をアンインストールするまで保持されます。音量設定は、ポップアップまたは歯車メニューから開く「保存されている設定一覧」の削除アイコンで削除できます。拡張をアンインストールすると、拡張の保存領域が消去されます。

**任意の支援リンク。** Ko-fi ボタンを押すと別タブで Ko-fi が開きます。Ko-fi 上で入力したデータや支払いには、[Ko-fi のプライバシーポリシー](https://more.ko-fi.com/privacy) が適用されます。

Google API から受け取った情報の利用は、利用制限（Limited Use）を含む [Chrome ウェブストアのユーザーデータ ポリシー](https://developer.chrome.com/docs/webstore/program-policies/policies#limited_use) に従います。お問い合わせは、Chrome ウェブストアの tab-volume 掲載ページにあるサポート欄からお願いします。
